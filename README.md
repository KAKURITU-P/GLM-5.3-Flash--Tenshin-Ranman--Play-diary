## 遊び方(前提)

ZCode の **Computer Use** 機能を使い、起動中のゲーム画面をスクリーンショットで読みながら
実イベント戦略のクリックでテキストを送り、画面の文章をその場で読解して進行しています。
選択肢は AI の判断で選ぶ運用(プレイヤー了承済み)。

## 操作メモ(KiriKiri エンジン向け)

- 合成クリックは無視されるため `strategy: "event"` で実イベントを送る
- クリック位置はテキストウィンドウ左(400, 592)に固定して誤爆を防止
- バックログを誤って開いたら `Escape` で閉じる
